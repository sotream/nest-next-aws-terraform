# observability-basics

Log groups, an alarm topic and the alarms that matter for this workload.

## What it does

- A log group `/<name_prefix>/<name>` per entry in `log_groups` (`api`, `web`, `migrate`) with retention and
  optional KMS encryption.
- An SNS topic for alarms, with an optional email subscription (the recipient has to confirm it).
- Alarms: load balancer 5xx, target 5xx per service, ECS CPU and memory per service, running tasks below
  desired per service (Container Insights), RDS free storage and RDS CPU. Missing data does not alarm.
- ECS service names are derived as `<name_prefix>-<service>`, the convention `ecs-service` uses, so the
  alarms exist before the services do.

## What it does not do

- No dashboards, no log metric filters, no anomaly detection, no paging integration beyond email.
- A customer-managed key passed in `kms_key_arn` must allow the `logs` and `cloudwatch` services to use it;
  the module does not edit key policies.

## Usage

```hcl
module "observability" {
  source                    = "../observability-basics"
  name_prefix               = "nnat-dev"
  log_groups                = ["api", "web", "migrate"]
  alarmed_services          = ["api", "web"]
  retention_days            = 14
  cluster_name              = "nnat-dev"
  alb_arn_suffix            = module.alb.alb_arn_suffix
  target_group_arn_suffixes = module.alb.target_group_arn_suffixes
  rds_instance_id           = module.rds.instance_id
}
```

### Requirements

| Name | Version |
| ---- | ------- |
| terraform | >= 1.11 |
| aws | ~> 6.68 |

### Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| alarmed\_services | ECS services (named <name\_prefix>-<service>) that get CPU, memory, task-count and 5xx alarms. | `set(string)` | n/a | yes |
| alb\_arn\_suffix | Load balancer ARN suffix, for alarm dimensions. | `string` | n/a | yes |
| cluster\_name | ECS cluster name, for alarm dimensions. | `string` | n/a | yes |
| log\_groups | Short names that get a log group named /<name\_prefix>/<name> (api, web, migrate). | `set(string)` | n/a | yes |
| name\_prefix | Prefix for every resource name, for example nnat-dev. | `string` | n/a | yes |
| rds\_instance\_id | RDS instance identifier, for alarm dimensions. | `string` | n/a | yes |
| retention\_days | Log retention in days. | `number` | n/a | yes |
| target\_group\_arn\_suffixes | Target group ARN suffixes keyed by service name. | `map(string)` | n/a | yes |
| alarm\_email | Email address subscribed to the alarm topic. Empty creates no subscription (the recipient must confirm it). | `string` | `""` | no |
| alb\_5xx\_threshold | 5xx responses generated by the load balancer, per 5 minutes, before alarming. | `number` | `10` | no |
| cpu\_threshold\_percent | CPU utilisation percent before alarming (ECS and RDS). | `number` | `80` | no |
| kms\_key\_arn | Customer-managed KMS key for log groups and the SNS topic. Its policy must allow the logs and cloudwatch services. | `string` | `null` | no |
| memory\_threshold\_percent | ECS memory utilisation percent before alarming. | `number` | `80` | no |
| rds\_free\_storage\_gib | Free database storage in GiB below which to alarm. | `number` | `5` | no |

### Outputs

| Name | Description |
| ---- | ----------- |
| log\_group\_arns | Log group ARNs. |
| log\_group\_names | Log group names keyed by short name. |
| sns\_topic\_arn | Alarm topic ARN. |
