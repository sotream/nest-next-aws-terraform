# Docs

- English, present tense, written for a reader who has not seen the repository.
- Decisions go in `docs/adr/NNNN-title.md` using `docs/adr/template.md`; supersede instead of rewriting history.
- Give commands with the expected result, link instead of repeating, and state what was not verified.
- Link the starter's ADRs by URL (`https://github.com/sotream/nest-next-starter/blob/main/docs/adr/...`).
- Module input and output tables are generated by `scripts/docs.sh`; edit only the text outside the markers.
